# Word Filter for SillyTavern

SillyTavern의 AI 메시지에서 지정한 표현을 삭제하거나 다른 표현으로 치환하는 확장입니다.

## v2.3.1 핵심 변경

- 모바일 브라우저의 오래된 템플릿 캐시를 우회해 관리 화면이 열리지 않던 문제를 수정했습니다.
- `template.html?v=2.3.1`을 `cache: no-store`로 먼저 읽고 실패할 때만 SillyTavern 기본 로더를 사용합니다.
- 빠른 연속 탭으로 관리 팝업이 중복 생성되지 않도록 열기 잠금을 추가했습니다.
- 원문 저장 모드에서 채팅 전환·과거 메시지 추가 로드·메시지 렌더링 이벤트를 감시하지 않습니다.
- 새 AI 응답은 `MESSAGE_RECEIVED`, 편집은 `MESSAGE_EDITED`에서 한 번만 처리합니다.
- 일괄 적용 뒤 전체 채팅을 다시 검증하던 두 번째 순회를 제거했습니다.
- 일괄 적용 뒤 보이는 메시지들을 자동으로 하나씩 다시 렌더링하지 않습니다.
- 저장 결과는 메시지 수 중심으로 단순화했습니다. `mes`와 `swipes[]` 저장 위치 수를 사용자 결과에 중복 표시하지 않습니다.
- 동일한 원문 문자열은 일괄 작업 동안 한 번만 필터 계산하고 결과를 재사용합니다.
- 업로드된 실제 226개 메시지 구조를 기준으로 AI 166개·사용자 60개 판별을 유지합니다.
- 요약 확장 예외는 `_summarizedHidden + is_system + 스와이프 구조` 조합으로 좁혀 일반 시스템 메시지를 보호합니다.

## 주요 기능

- 삭제 단어 및 순서형 치환 규칙
- 한국어·영어·일본어·중국어·기타 및 사용자 정의 그룹
- 언어별 정규식 텍스트 내보내기
- 표시 전용 모드와 실제 채팅 원문 저장 모드
- 현재 채팅 전체 일괄 적용과 원문 복원
- JSON 설정 백업·가져오기
- 모바일 대응 UI

## 설치

1. SillyTavern을 완전히 종료합니다.
2. 기존 `scripts/extensions/third-party/word-filter` 폴더를 삭제하거나 백업합니다.
3. ZIP 안의 `word-filter` 폴더를 `scripts/extensions/third-party/`에 넣습니다.
4. 최종 경로를 확인합니다.

```text
scripts/extensions/third-party/word-filter/manifest.json
scripts/extensions/third-party/word-filter/index.js
scripts/extensions/third-party/word-filter/style.css
scripts/extensions/third-party/word-filter/template.html
```

5. SillyTavern을 재시작하고 관리 화면 상단에서 `v2.3.1`을 확인합니다.

기존 v1·v2·v2.1·v2.2 설정과 백업은 그대로 읽습니다.

## 현재 채팅 원문 변경

일괄 적용은 화면에 표시된 최근 메시지만 보지 않고 현재 `context.chat` 전체를 순회합니다.

- 각 AI 메시지의 `message.mes`
- 각 AI 메시지의 모든 `message.swipes[]`

일부 오래된 채팅은 `mes`와 활성 스와이프가 서로 다르므로 두 저장 위치 모두 바꿔야 복원과 스와이프 전환이 안전합니다. 다만 두 위치의 원문이 완전히 같으면 필터 결과를 한 번만 계산해 양쪽에 기록합니다.

v2.3.1은 작업 뒤 같은 채팅을 다시 전부 검증하지 않고 `saveChat()`을 한 번 호출합니다. 또한 보이는 메시지를 자동으로 재렌더링하지 않습니다. 따라서 원문 저장은 완료됐지만 현재 화면에는 잠시 이전 문장이 남을 수 있습니다.

다음 중 하나로 화면을 갱신합니다.

- 채팅을 다른 곳으로 전환했다가 다시 열기
- 결과 카드의 `현재 화면 새로고침` 버튼 누르기

자동 재렌더링을 제거한 것은 긴 채팅에서 Markdown 렌더링이 연속 실행되는 버벅임을 피하기 위한 선택입니다.

## 표시 전용 모드

저장된 `message.mes`는 바꾸지 않고 화면에만 필터 결과를 표시합니다. 메시지 수정 버튼을 누르면 SillyTavern이 저장한 실제 본문이 textarea에 표시됩니다.

표시 요청은 메시지 ID별 대기열로 합쳐 처리하며, 같은 규칙·같은 원문으로 이미 표시된 메시지는 다시 렌더링하지 않습니다.

## 원문 저장 모드

원문 저장 모드에서는 평소 다음 이벤트만 처리합니다.

- 새 AI 응답: `MESSAGE_RECEIVED`
- 메시지 편집: `MESSAGE_EDITED`
- 스와이프 전환: `MESSAGE_SWIPED`

`CHARACTER_MESSAGE_RENDERED`, `CHAT_CHANGED`, `MORE_MESSAGES_LOADED`, `MESSAGE_DELETED`에서는 원문 저장 작업을 실행하지 않습니다. 따라서 채팅을 열거나 과거 메시지를 불러오는 것만으로 전체 메시지를 다시 필터링하지 않습니다.

## 백업과 복원

원문 저장 모드는 실제 채팅 데이터를 변경합니다. 대부분의 백업은 전체 문장을 복제하지 않고 변경 위치, 삭제된 문자열, 삽입된 문자열을 저장합니다.

복원 시에는 `mes`와 저장된 스와이프의 백업을 되돌립니다. 사용자가 필터 적용 후 직접 수정해 해시가 달라진 항목은 충돌로 건너뜁니다. 복원 후에도 자동 전체 재렌더링은 하지 않으며 결과 카드의 화면 새로고침을 사용할 수 있습니다.

## 정규식용 내보내기

언어 그룹과 포함 대상을 선택하면 다음처럼 복사하거나 TXT로 저장할 수 있습니다.

```text
mechanical|rhythmic|금지어3|금지어4
```

## 주의

- 중요한 채팅은 원문 저장 모드를 쓰기 전에 별도로 백업하는 것이 안전합니다.
- 일괄 적용 결과의 `필터 대상 AI 메시지`가 예상과 다르면 채팅 JSON 구조와 메시지 판별 값을 확인해야 합니다.
- 현재 화면 새로고침은 선택 동작입니다. 원문 저장 자체에는 필요하지 않습니다.
